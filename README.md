# Mindful Haven

A mental health resource center built with React, TypeScript, Tailwind CSS, and Supabase.

## Getting Started

```bash
npm install
npm run dev
```

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS + shadcn/ui
- Supabase (auth + database)
- TanStack React Query
- React Router v6
